# 激发态、TDDFT 和电子光谱

| 任务 | 重点核对 |
| --- | --- |
| 垂直吸收、TDDFT/TDA/CIS | 确认基态几何、SCF 参考态、目标自旋、根数、能量窗口、收敛及振子强度。用态特征解释强峰、暗态、电荷转移和局域激发。说明谱线展宽与单位。 |
| 激发态优化或柔性扫描 | 核对每一步实际计算的根数、被用于梯度的态及收敛几何。比较相邻点能量、主要跃迁、NTO、空穴–电子分布或可用的态重叠，识别有无态排序变化、强混合和目标态漂移。 |
| 荧光与磷光 | 区分垂直吸收、发射和绝热能隙的几何及初末态。确认发射来自用户指定的激发态几何。磷光强度通常涉及自旋轨道耦合，常规跃迁输出所含物理量需按方法核实。 |
| 激发态频率、交叉与非绝热问题 | 验证频率属于正确的目标态和构型，检查该方法与版本的导数支持。势能面交叉、锥形交叉或近简并体系需核对方法适用性、态混合与目标物理量。 |
| 振电光谱 | 按实际 Franck–Condon/Herzberg–Teller 等模型，核对初末态几何、频率、原子对应及位移，检查是否采用 Duschinsky 混合、温度、跃迁偶极导数和线形处理。 |
| ECD、光谱归属和电荷转移 | 记录谱量、旋光强度约定、构象权重、溶剂和带宽。电荷转移用实际空间分布或态特征支持，轨道能隙与激发能分别报告。 |

## 态身份发生变化时

若 A→B 电荷转移在初始构型排第二，在优化末段主要出现在第三根，而第二根成了 B 上局域激发，说明目标态身份需要沿路径查证。输出被用于梯度的根与目标态在哪一步开始偏离，核对可用的 NTO、组态权重或态重叠。接近简并时可比较多个连续点和多个根。只有端点数据时，报告端点看到的态排序和特征。评估增加求根范围、在关键构型重算或分段追踪时，给出核对准则和适用范围。最终依据目标态上的梯度、构型与激发态性质验收。

## 模型和解释

- 对长程 CT、Rydberg、双激发特征或近简并，检查泛函、基组（包括弥散函数）、参考态和所用激发理论能描述的物理效应。将更换泛函或方法明确列作模型敏感性检查。
- 使用 PCM/SMD 时区分基态和激发态各自的几何与溶剂响应，核对垂直、弛豫和发射步骤。按相应 Gaussian 版本确认关键词组合与输出位置。
- 比较实验光谱时说明体系及构象、电荷态、环境、温度、峰展宽和权重。针对问题报告相关能量和强度，优先检查能量窗口覆盖。
