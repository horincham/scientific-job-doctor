# 单点能、SCF、波函数与相关能

## 按阶段验收

- **HF、DFT、半经验。** 确认目标运行的最终几何、模型、电子数和实际收敛信息。多步骤优化中的 SCF 能量属于各自构型。解析 `SCF Done` 时同时检索同一步附近的 `Convergence criterion not met` 等失败提示。
- **MP2、双杂化、CCSD(T) 等。** 识别基准参考态和后 HF 阶段，查最终方法特有的总能量与收敛信号。CCSD 迭代中的相关能与最终 `(T)` 修正属于不同输出阶段。若任务在积分变换、耦合簇或三重激发修正时中断，按已完成阶段记录结果。
- **G 系列、CBS、用户定义复合方案。** 查整体最终汇总及所求物理量，核对各子步骤、原子/片段参照、零点与热修正约定。用任务方法的最终能量字段收集数据。
- **反应、解离、原子化与自旋能差。** 先列反应式或差分式，确认计量、电荷、参考自旋态、哈密顿量、赝势/相对论处理及能量单位。若采用高水平单点加低水平热修正，明示每一项来源并核实几何、态、相和参考定义。

## SCF 决策

1. 判断同一几何的 SCF 是内部达到迭代上限，还是被作业层中断。检查失败点在初始结构、优化后段、扫描某点、片段或 CP 子任务。根据可见的密度变化、能量趋势和残差区分持续下降、振荡和突跳。摘要未显示迭代历史时，结论限定在已观察证据。
2. 看化学与数值前提。核对电荷、多重度、初始几何、片段和短接触、轨道占据及前一步态。若源自弥散基组、很近的中心、重原子赝势或对称约束，查重叠矩阵/线性依赖相关警告、基组与对称性。保留当前结果的参考定义。
3. 若持续改善且接近阈值，可评估增加允许迭代数。持续振荡或占据翻转时，优先评估更合适的轨道初猜、原有 SCF 算法及该方法支持的稳定化策略。常规 DIIS 失败时可评估 `SCF=XQC`，同时检查是否已使用、方法限制及额外费用。调整 DFT 积分格点等数值设置后，按最终方案重新验收关键比较点。对高成本任务优先用最具判别力的单点测试。
4. 达到数值收敛后核对电子态。比较 `⟨S²⟩` 与纯自旋态 `S(S+1)`，联看自旋密度、占据、轨道与化学目标。破缺对称、反铁磁耦合和近简并体系需要单独解释。对于适用方法，检查波函数稳定性，若 `Stable=Opt` 找到不同解，重新核对该解上的性质及几何/频率的自洽性。稳定性分析给出的是指定变分空间内的局部信息。

对过渡金属、开壳层和断键态，以多个合理电子解、占据与化学性质判断。对强静态相关的体系，利用自然轨道占据、多个电子解、适用时的耦合簇诊断和方法敏感性评估单参考可靠性。指标阈值依参考态和化学问题解释。
