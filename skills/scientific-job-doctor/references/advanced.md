# 多参考、分层模型、性质与动力学

| 任务 | 取证、科学判据与下一步 |
| --- | --- |
| **CASSCF 与多参考** | 记录活性电子数、活性轨道数与轨道形状、组态或自然占据、目标根、自旋、态平均权重。检查活性轨道是否在迭代或变构型时换出，目标态是否连续。按反应涉及的成键/反键、近简并或金属轨道核对活性空间，在代表性构型做敏感性检查。区分轨道/CI 收敛与活性空间足够，跨几何比较时保持态和活性空间定义可追溯。 |
| **ONIOM/QM-MM** | 核对原子与层划分、model/real、层间 link atom、力场原子类型和参数、电荷/多重度与嵌入方案。对两层常见减法表达检查 `E_high(model) + E_low(real) − E_low(model)` 与各子计算。确认研究位点在适当的高层区域、边界落点与约束合理，比较边界或层大小的敏感性。 |
| **Population、NBO、ESP、RESP 和 cube** | 核对实际电子密度的来源（SCF、相关密度、基态或激发态）、NBO 版本和关键输出、原子顺序、总电荷与拟合网格。原子电荷依分析方案定义，横向比较时保持方法、基组、密度和拟合条件。查 cube 的网格、坐标单位、原点和原子顺序，差分图要求同一可比较网格。 |
| **NMR、EPR** | 区分 NMR 绝对屏蔽与相对参比的化学位移。确认核种、参比、构象及溶剂平均、规范处理与张量约定。EPR 核对未配对自旋态、g 张量/超精细耦合和单位，检查参考波函数。 |
| **外场、偶极、Polar、响应和非线性光学** | 核对实际坐标朝向、场方向、单位、静态或频率依赖条件及密度来源。有限差分核对场强、正反步和敏感性，涉及向量或张量时对齐坐标系。 |
| **半经验、MM 与外部接口** | 核对所用参数是否覆盖元素、电荷、键型和任务导数，核对外部程序、接口输入输出、单位和梯度符号。脚本和外部调用报错时按发起程序、子程序及回传错误定位。 |
| **BOMD/ADMP** | 拿到轨迹、积分步长、每步电子收敛、能量各项和温度。检查步数连续性、重启、跃迁或突变前后的几何和力，依所用积分器及动力学方案解释能量守恒。对反应事件核对关键键与邻近帧。 |
| **PBC 与少见模块** | 检查版本、route、周期维数和实际晶胞、边界、采样与电荷模型。根据对应模块的手册确认关键字、几何定义、单位、已完成输出及有效性。将未知模块先定位到实际计算段，再查询版本相符的官方或作者示例。 |

专业判断按证据分级。几何、波函数、密度或轨迹缺失时先报告可读到的阶段性事实，再指出需要的文件与检查。不同程序转移轨道时，核对原子排序、基组收缩、球谐/笛卡尔约定、轨道归一化及 ECP 定义。

资料依据见[来源索引](sources.md)的 MOKIT、ONIOM、Multiwfn 和厂商关键词入口。
